# DION — Почта и Доски

Frontend-прототип двух экранов корпоративной платформы **DION**: почтового
клиента и раздела «Доски» (whiteboards), реализованный по макетам Figma
(«Design system» + «DION perspective») и адаптированный под архитектуру
проекта.

## Стек

- **React 19 + TypeScript** (strict), **Vite** — сборка и dev-сервер
- **react-router-dom** — маршрутизация между разделами приложения
- **CSS Modules** + дизайн-токены на CSS custom properties — без сторонних
  CSS-фреймворков, чтобы не плодить параллельную дизайн-систему
- **lucide-react** — набор иконок (см. «Известные допущения» ниже)
- **oxlint** — линтинг

## Запуск

```bash
npm install
npm run dev       # dev-сервер, http://localhost:5173
npm run build     # typecheck + production-сборка
npm run lint      # oxlint
npm run preview   # локальный просмотр production-сборки
```

## Структура проекта

```
src/
  app/            # роутер верхнего уровня
  layout/         # каркас приложения: боковая иконочная панель, AppShell
  components/     # переиспользуемые UI-компоненты дизайн-системы
                   # (Button, IconButton, Input, Checkbox, Avatar, Badge,
                   #  NavigationItem, Modal, Menu, TextButton)
  features/
    mail/         # экран «Почта»: навигация по папкам, список писем,
                   # панель чтения, модалка написания письма
    whiteboards/  # экран «Доски»: навигация, сетка досок, переименование,
                   # дублирование, удаление
  styles/         # design tokens (tokens.css) и глобальные стили
```

Каждый компонент дизайн-системы — это пара `Component.tsx` +
`Component.module.css`; данные разделены на `types.ts` и `data/*.ts`
(типизированные моки), бизнес-логика экрана живёт в `FeaturePage.tsx`.

## Дизайн-токены

`src/styles/tokens.css` — прямое отражение переменных, полученных из Figma
(`color/…`, `spacing/general/…`, `radius/…`, `typography/…`). Имена токенов
специально сохраняют структуру исходных Figma-переменных, чтобы изменения
в дизайн-системе было легко сопоставлять с кодом.

## Известные допущения

Часть исходных материалов была недоступна из этого окружения (сетевые
ограничения окружения блокировали скачивание бинарных ассетов с
`figma.com` и доступ к внутреннему Storybook `frontend-dev02.dev.dion.vc`).
Из-за этого:

- **Иконки** — не оригинальные SVG из Figma, а сопоставленные по смыслу
  иконки из открытой библиотеки `lucide-react` (то же геометрическое
  ощущение: тонкая обводка, 16–24px).
- **Шрифты** — вместо брендовых `VTB Group UI` / `TikTok Sans` используется
  системный шрифтовой стек; кегли, начертания и межстрочные интервалы
  сохранены по токенам.
- **Аватары и иллюстрации досок** — сгенерированы (инициалы на цветном
  фоне; градиентные плашки для превью досок) вместо оригинальных растровых
  ассетов.
- Цвет тёмной иконочной панели не был явно указан в exported-коде
  компонента (там был указан светлый fallback-токен, не совпадающий со
  скриншотом), поэтому взят ближайший тёмный токен дизайн-системы
  (`color/common/contrast`) вместо произвольного нового hex-значения.
